# LogicLab

Visualizzatore interattivo per imparare le porte logiche AND e OR. Cambia gli input A e B e osserva in tempo reale il segnale, l'output, l'espressione e la riga corrispondente nella tabella di verità.

## Avvio locale

Richiede Node.js 22.13 o superiore.

```bash
npm install
npm run dev
```

Apri `http://localhost:3000`.

## Comandi

- `npm run dev` — ambiente di sviluppo
- `npm run build` — build di produzione
- `npm test` — build e verifica del rendering

Realizzato con React, Next.js, Tailwind CSS e vinext.
